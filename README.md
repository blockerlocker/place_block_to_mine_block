For Minecraft 26.4

Players cannot break blocks normally. Instead, whenever a block is placed, it destroys the block the player placed it on. This means you need at least one block in order to start mining things, for example a piece of wool from killing a Sheep. Not any block can break any other block though, blocks still follow the typical Minecraft tool structure;
- Wooden, Copper, and Gold blocks are used to break Stone blocks
- Stone blocks are used to break Iron blocks
- Iron blocks are used to break Diamond blocks
- Diamond blocks are used to break Obsidian, Ancient Debris, and Netherite blocks

While any block can be used to mine blocks that do not have a tool tier requirement, only blocks that do NOT require support can be used to break any pickaxe-mineable blocks. For example, you can use Wooden Buttons to break Dirt or Sand, but you cannot use Wooden Buttons to break Coal Ore or Stone.

This pack uses the data pack library [Iris by Aeldrion](https://github.com/Aeldrion/Iris) in order to detect block placement. I am not using the outdated release version, I've made some tweaks to the generation script so that I can build a version compatible with the latest versions of Minecraft.
