For Minecraft 26.4

Players cannot break blocks normally. Instead, whenever a block is placed, it destroys the block the player placed it on. This means you need at least one block in order to start mining things, for example a piece of wool from killing a Sheep.

This pack uses the data pack library [Iris by Aeldrion](https://github.com/Aeldrion/Iris) in order to detect block placement. I am not using the outdated release version, I've made some tweaks to the generation script so that I can build a version compatible with the latest versions of Minecraft.
